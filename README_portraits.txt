Safer Discounts · 8 generated academy portraits

The code on GitHub main already references assets/academy-portrait-{lang}.webp and has a fallback photo if files are not present.

Upload: open https://github.com/saferdiscounts/saferdiscounts.com/tree/main/assets and choose Add file > Upload files. Drag all eight .webp files into that folder and commit to main.

Alternatively run upload_academy_portraits.ps1 in Windows PowerShell if Git is installed and push access is configured.

Languages: ptbr Brazilian Portuguese, en English, it Italian, es Spanish, fr French, de German, ru Russian, pt European Portuguese.

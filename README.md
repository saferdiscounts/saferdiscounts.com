# سافر Discounts — دليل تعديل الموقع

الموقع اتصمم بحيث تقدر تعدله بنفسك من غير ما تحتاج مبرمج، من خلال ملف واحد اسمه `index.html`.

## إزاي تفتح الملف عشان تعدله؟

1. ادخل على الريبو بتاعك على GitHub.
2. دوس على ملف `index.html`.
3. دوس على أيقونة القلم ✏️ (Edit this file) اللي هتلاقيها فوق يمين محتوى الملف.
4. عدّل اللي محتاجه (حسب الأقسام تحت).
5. انزل تحت ودوس **Commit changes** عشان الموقع يتحدث تلقائيًا خلال دقيقة أو اتنين.

كل البيانات القابلة للتعديل موجودة في أول الملف جوه بلوك اسمه `SITE_CONFIG`، وكل سطر فيه معلق عليه بالعربي عشان تعرف تعدل بسهولة.

---

## 1) تغيير رقم الواتساب / التليفون / الإيميل / الفيسبوك

في أول الملف، هتلاقي:

```js
contact: {
  whatsappNumber: "201116666306",
  whatsappDefaultMessage: "مرحباً، عايز أحجز",
  phoneDisplay: "01101576669",
  phoneDial: "+201101576669",
  email: "info@saferdiscounts.com",
  facebook: "https://www.facebook.com/saferdiscounts/"
}
```

غيّر أي قيمة هنا (بين علامتي التنصيص "") وهتتحدث تلقائيًا في كل زرارات الموقع (فوق، تحت، وفي قسم التواصل، والزرار العائم).

---

## 2) إضافة أو تغيير صور الوجهات السياحية

الصور بتتحط في فولدر اسمه `images` جنب `index.html`.

**لإضافة صورة جديدة:**
1. من صفحة الريبو الرئيسية، دوس **Add file → Upload files**.
2. ارفع الصورة (مثلاً `dubai.jpg`) واختار إنها تترفع جوه فولدر `images`.
3. تأكد إن اسم الصورة اللي رفعتها مطابق للاسم الموجود في `SITE_CONFIG` تحت `destinations`.

**لإضافة وجهة جديدة بالكامل:**
في `index.html` هتلاقي:

```js
destinations: [
  { name: "دبي", group: "خارج مصر", image: "images/dubai.jpg" },
  { name: "باريس", group: "خارج مصر", image: "images/paris.jpg" },
  ...
]
```

انسخ سطر وغيّر الاسم والمجموعة (داخل مصر / خارج مصر) واسم ملف الصورة.

> لحد ما ترفع صورة حقيقية، هيظهر مكانها شكل بسيط بديل، مش هيبوظ شكل الموقع.

---

## 3) تعديل نصوص الصفحة الرئيسية أو الخدمات أو "ليه احنا"

كل النصوص دي موجودة في نفس `SITE_CONFIG`:
- `hero` → نص الصفحة الرئيسية
- `services` → خدماتك (طيران / فنادق / فعاليات)
- `why` → ليه سافر Discounts
- `steps` → خطوات الحجز

عدّل أي نص بين علامتي التنصيص براحتك، وسيب باقي التنسيق (الأقواس `{ }` والفواصل `,`) زي ما هو.
